# agents-library

Библиотека различных агентов (в меньшей степени) и радиокоманд фракций (в большей)

## о чём здесь

Soundpad и адекватные прослушивание звуковых линий агентов и фракций в csgo/cs2
Сейчас реализован второй вариант через dropdown

## в данный момент

* Все фракции csgo, большинство агентов
* Большинство радиокоманд (некоторые вырезаны по причине иррелевантности)

## о развертывании и доступе

Проект полностью собирается самостоятельно, доступ куда-либо не требуется. Из-за величины чанков бинарных данных первая загрузка dev будет очень долгой, на проде (npm run preview в помощь) все быстро загружается
