# CS2 Agents Library — План разработки

## Текущее состояние

- Маршруты: `/`, `/about`, `/steve`, `/sally`
- `Agent`: id, name, fraction, description, comment, voiceLines, photos
- `AgentPage.vue` → `AudioContent.vue` (аккордеон с раскрывающимися секциями)
- Vite резолвит аудио/картинки через `import.meta.glob` — паттерн работает, трогать не нужно

## 1. Структура данных (что менять)

Сейчас фракция — просто строка. Нужна иерархия:

```
Фракция (Faction): Professionals, SWAT, GIGN, ...
  └── Субфракция (Subfraction): мужчины / женщины / мастерские
        └── Агент (Agent): Sally, Steve, ...
```

### Изменения в интерфейсах

**`Agent`** — добавить:
```ts
subfraction: string           // 'male' | 'female' | 'workshop'
modelPath?: string            // путь к 3D-модели (на будущее)
```

**Новые интерфейсы**:
```ts
interface Subfraction {
  id: string
  name: string                // 'Женщины', 'Мужчины', 'Мастерские агенты'
  agents: Agent[]
}

interface Faction {
  id: string
  name: string                // 'Professionals', 'SWAT', ...
  subfractions: Subfraction[]
}
```

**`sally.ts`** — обернуть в Subfraction/Faction или просто добавить поле `subfraction: 'female'`.

### Pinia Store

`useFactionStore` — хранит выбранную фракцию, субфракцию, индекс текущего агента.

## 4. UI Вариант 1 — Кнопки-сетка (soundboard)

- Grid кнопок, каждая = категория голосовых линий (например "Убийства", "Победа")
- Клик → `Math.random()` выбирает случайный файл из категории → воспроизведение
- Composable `useAudioPlayer`: останавливает предыдущий звук при новом клике
- Компонент: `AudioGrid.vue`

**Плюсы**: динамично, как soundboard, приятно тыкать  
**Минусы**: нет контроля — каждый раз разный звук

### Место для 3D-модели
- Десктоп: слева или справа от сетки кнопок (`position: sticky`)
- Мобилка: отдельная вкладка / вторая страница свайпом

## 5. UI Вариант 2 — Дропдауны

- Каждая категория = дропдаун (кастомный `<select>` или кастомный компонент)
- Расположение: сетка или колонка (как сейчас в AudioContent)
- Выбор конкретного трека → play
- При 99 категориях у Sally нужен поиск/фильтр по категориям

**Плюсы**: точный выбор, можно переслушать конкретную фразу  
**Минусы**: 99 дропдаунов выглядят громоздко — нужна группировка

## 6. Слайдер агентов

Когда в субфракции несколько агентов:

```
← [Sally] [Steve] [???] →     ← ручное перелистывание
          ●○○                  ← точки-индикаторы
```

- Ручное: кнопки prev/next + drag/swipe (touch-события)
- Авто: `setInterval` + пауза при наведении/клике
- Реализация: `useAgentSlider` composable + Pinia для глобального состояния
- Анимация: Vue `<Transition>` с `slide-left` / `slide-right`

## 7. 3D Модели

Самая сложная часть. Модели CS2 в формате Source 2 (`.vmdl`, `.vmat`).

| Вариант | Сложность | Описание |
|---------|-----------|----------|
| A. PNG-рендеры | Легко | Заранее сделанные рендеры из Source 2 Viewer |
| B. Three.js + .glb | Средне | Конвертация через Source2Viewer → .glb, рендер через @tresjs/core |
| C. Sketchfab embed | Легко | iframe с моделями сообщества (зависимость от чужого сервиса) |
| D. Babylon.js | Средне | Альтернатива Three.js, хорошая документация |

**Рекомендация**: начать с PNG-рендеров (вариант A), место под 3D заложить архитектурно.  
Для конвертации моделей: [Source2Viewer](https://valveresourceformat.github.io/) умеет экспорт в GLTF.

## 8. Android-приложение

- **Capacitor** (от Ionic) — оборачивает Vite/Vue в нативный WebView
- Шаги: `npm install @capacitor/core @capacitor/cli` → `npx cap add android` → Android Studio
- Аудио-файлы (WAV) бандлятся в APK — будет большой, но работает офлайн
- WAV → MP3/OGG конвертация уменьшит размер в 5-10x

## 9. Vue-оптимизации для изучения

| Фича | Применение |
|------|-----------|
| `import.meta.glob` lazy | Загружать аудио только при открытии секции |
| `defineAsyncComponent` | Ленивая загрузка тяжёлых страниц/виджетов |
| `v-memo` | Кешировать статичные карточки агентов в слайдере |
| `Pinia` + `storeToRefs` | Реактивный стейт без лишних ререндеров |
| `Vue Transition` | Анимации слайдера и переходов между агентами |
| `useIntersectionObserver` | Загружать аудио по мере прокрутки |
| Vite code splitting | Разделить сборку по фракциям |
